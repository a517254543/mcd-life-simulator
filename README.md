输入：**25 岁 · 程序员 · 上海 · 月收入 12000 · 单身 · 每周 3 次**
（门店 1450713，数据 2026-10-13 实测）

```
《你的麦门人生报告》
报告编号 MCD-2027-1013 · 门店 1450713 · 数据日期 2026-10-13

━━━ 2027 年人生轨迹 ━━━
你成为了一名资深程序员。
因为长期锁定凭券 9.9 元的早餐两件套，
你的早餐决策时间减少了 87% —— 省下的精力全部用来和产品经理 battle。

━━━ 隐藏属性 ━━━
效率 +15   9.9 元早餐券省掉了每天早上的「吃什么」谈判
快乐 +20   本月联名周边与龙焰系列双重上新
脂肪  +8   按每周 3 次、每次约 500 kcal 折算的趣味估算
钱包  -6   但 49 元 150 天的麦金学期卡把场均成本打了回去

━━━ 人生关键词 ━━━
「代码改变世界，麦当劳填满胃。」

━━━ 你的专属套餐 ━━━
工作日 · 麦香鸡 ¥17 + 浓缩咖啡 ¥15
  蛋白质 15g、钠 731mg，资深程序员的基础操作
加班夜 · 双层吉士汉堡 ¥23
  牛肉加吉士，凌晨的编译器需要这个

━━━ 本月麦门运势 ━━━
上上签  联名复古棒球帽在售，任意消费加 39.9 元可得
小吉    中薯条买一送一、9.9 元中杯冰美式当前可领
注意    龙焰芝士棒鸡腿堡名字带「芝士」，配料表里没有吉士
         —— 像极了我简历上写的「精通」二字

━━━ 人生建议 ━━━
不要在凌晨 2 点修改生产环境。

以上餐品、价格、优惠与活动均来自麦当劳 MCP 实时数据（门店 1450713，2026-10-13）。
「脂肪」等属性为娱乐性推算，不构成营养或医学建议。
餐品供应与价格以门店实际为准。
```

**注意「专属套餐」和「本月运势」**：
麦香鸡 ¥17、浓缩咖啡 ¥15、双层吉士汉堡 ¥23，来自 `query-meals` 实时返回；
9.9 元早餐两件套、联名棒球帽 +39.9 元、中薯条买一送一，
来自 `available-coupons` 与 `campaign-calendar` 的当前数据。
「龙焰芝士棒鸡腿堡名字含芝士、配料表无吉士」这条反差，
是用 `query-meal-detail` 逐项验证过的。

**虚构一个菜单项，用户到店点不出来，报告就失去了全部乐趣。**
所以这个 Skill 的每一行推荐都能追到 MCP 字段。

> 复现方式：接入 MCP 后输入「25 岁程序员，上海，月入 12000，单身，每周吃 3 次麦当劳，帮我算一版麦门人生」。
> 换个城市、换个人设，报告完全不同 —— 运势和套餐跟着当地门店的真实数据变。

## 它和娱乐生成器的区别

市面上的「人生模拟器」是纯文本生成：编几个菜名，配一个价格，截图很美好，
用户照着点，店里没有。

本项目的定位是**娱乐外壳 + 真实数据内核**：

| 层 | 内容 | 来源 |
|---|---|---|
| 娱乐层 | 人生轨迹、隐藏属性、人生关键词、人生建议 | AI 创作（有文案规则约束） |
| 数据层 | 专属套餐、价格、优惠券、当月活动、营养折算 | **麦当劳 MCP 实时返回** |

娱乐层负责传播（MBTI 式「测测你的人生」自带分享属性），
数据层负责落地（推荐的东西真的能点到、价格真的对得上）。

文案规则见 [`references/report-template.md`](references/report-template.md)：
- 幽默指向处境，不指向人 —— 不评价收入、外貌、感情状态
- 月收入只用于匹配套餐价位带，不做任何消费能力评价
- 「脂肪 +8」必须附 kcal 折算依据，且明确标注是娱乐推算
- 报告头固定带门店编号与数据日期

## 工作原理

```
① query-nearby-stores   按城市定位门店 → storeCode
② query-meals          拉该店真实在售菜单与价格      → 专属套餐
③ available-coupons    当前可领优惠券                → 小吉
④ campaign-calendar    当月营销活动日历              → 上上签
⑤ list-nutrition-foods 营养数据                     → 脂肪属性折算
⑥ AI 按模板生成报告     六段结构 + 九条自检清单
```

唯一需要判断力的地方在第 ⑥ 步之前：
**运势里那条「注意」行的素材必须是验证过的名实不符项。**
比如「龙焰芝士棒鸡腿堡」——名字里有芝士，配料表里没有吉士，
这条反差要用 `query-meal-detail` 拉过配料才敢写。
没有验证过的反差不写，宁可少一条，不可编一条。

细节见 [`MCP_INTEGRATION.md`](MCP_INTEGRATION.md)。

## 快速开始

### 前置

在 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) 申请麦当劳 MCP Token。

### 1. 配置连接器

WorkBuddy / Cherry Studio / Cursor / Trae 等支持 Streamable HTTP 的客户端均可。

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

仓库内 [`mcp-config.example.json`](mcp-config.example.json) 使用 `${MCD_MCP_TOKEN}`
环境变量占位符，不含任何真实凭证。

### 2. 安装 Skill

```
mcd-life-simulator/
├── SKILL.md
└── references/
    ├── report-template.md   # 报告模板 + 文案规则 + 属性换算规则
    └── mcd-tools.md         # 5 个工具的字段速查与 10 个实测数据陷阱
```

放入你的 Skill 目录后即可对话使用。

### 3. 直接问

```
25 岁，程序员，上海，月入 12000，单身，每周 3 次麦当劳，帮我算一版麦门人生
我在成都，做销售，已婚有娃，每月吃 1 次，给我也算算
换个城市再算一版
```

## 实测状态

**已验证**（门店 1450713，2026-10-13）：
`query-nearby-stores` · `query-meals` · `available-coupons` · `campaign-calendar` · `list-nutrition-foods`
